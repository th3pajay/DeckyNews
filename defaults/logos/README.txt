Static Source Logos (128x128px PNG)
=======================================

This directory contains static logo files for news sources.
Logos are served via /defaults/logos/<source>.png paths.

Required logos:
- ign.png - IGN logo (orange/red theme)
- pcgamer.png - PC Gamer logo (red theme)
- steam.png - Steam logo (blue theme)
- kotaku.png - Kotaku logo (green theme)
- gamespot.png - GameSpot logo (yellow/black theme)
- polygon.png - Polygon logo (pink/purple theme)

Note: Actual logo files must be created/downloaded separately.
For development, placeholder images can be used.
